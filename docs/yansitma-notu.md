# Yansıtma Notu

Bu projede yapay zekâdan iki yerde yararlandım: eklentinin kodunu Claude Code ile yazdırdım, kararları ve hata ayıklamayı sohbet asistanıyla yürüttüm. Claude Code eklentinin bütün kodunu ve 258 birim testini yazdı. contenteditable alanındaki metnin rapora sızdığını kendisi buldu ve düzeltti. Skor formülünün siteleri hep 2-12 arasına yığdığını koddan gösterdi. Halüsinasyon kontrolünde de DevTools'a yapıştırabileceğim tek satırlık komutlar hazırladı, böylece 15 bulguyu hızlıca elle kontrol ettim.

Yapay zekâ birçok yerde yanıldı. Sohbet asistanı Gemini anahtarının "AIza" ile başlayacağını söyledi, benimki "AQ." ile başlıyordu. "Kota yeter" dedi, günlük sınır 20 çıktı. Claude Code'un kodunda mimeType yanlış yazılmıştı, bu yüzden Gemini 400 hatası verdi. LLM de hata yaptı. Ankara'da "h1 yok" dedi, ben DevTools'ta 10 tane gördüm, çünkü LLM'e giden envantere hiç h1 girmemişti. Acıbadem'de bağlantının içindeki "Eğitim" başlığını tıklanamaz sandı. Aynı sayfayı 3 kez analiz ettiğimde LLM skoru 52,4 ile 73,4 arasında oynadı. Claude Code'un yazdığı bir betik de README'nin başına bozuk satırlar ekledi. Claude Code bunu fark edip geri aldı.

Hataları farklı yollarla fark ettim. 429 hata kutusu, git status ve claude --version çıktıları sorunları gösterdi. Deterministik skor 2,7 iken LLM'in 100 vermesi iki katmanın çeliştiğini ortaya çıkardı. LLM'in "h1 yok" iddiasını DevTools'ta h1 sayısına bakarak çürüttüm. Klavyeyle randevu almak 8-9 dakika sürdü, ama araç yalnızca ana sayfayı analiz ettiği için bu zorluğu ölçemedi. Bu yüzden yapay zekânın çıktısını kanıt olarak değil, kontrol edilecek bir iddia olarak ele almam gerektiğini öğrendim.
